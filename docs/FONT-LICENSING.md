# Font Licensing Report — mycroft.io website

All fonts used on the website are **self-hosted** (the font files live on your
own server, with no dependency on Webflow, Google, or any other third party)
and **100% free for commercial use**. There are no licensing fees,
subscriptions, or renewals — now or in the future.

| Font | Role on the site | License | What that means for you | Source |
|---|---|---|---|---|
| **TASA Orbiter** | Main font for body text, buttons, and menus | SIL Open Font License (free) | Free for commercial use forever. No fees, no attribution required. | [Official GitHub release](https://github.com/localremotetw/TASA-Typeface-Collection) |
| **Newsreader Display** | The serif font used in large headlines | SIL Open Font License (free) | Same as above — free forever with no conditions on normal use. | [Google Fonts](https://fonts.google.com/specimen/Newsreader) |
| **Inter** | Older font still used in a few places | SIL Open Font License (free) | Same as above. | [Google Fonts](https://fonts.google.com/specimen/Inter) |
| **Libre Baskerville** | Older font still used in a few places | SIL Open Font License (free) | Same as above. | [Google Fonts](https://fonts.google.com/specimen/Libre+Baskerville) |
| **General Sans** | Loaded by the site but barely used | Fontshare Free Font License (free) | Free for commercial use, including on websites. The only restriction is that the font files can't be re-shared as a standalone download — which doesn't apply to using them on your site. | [Fontshare](https://www.fontshare.com/fonts/general-sans) · [License terms](https://www.fontshare.com/licenses/itf-ffl) |
| **webflow-icons** | A small set of icons (arrows, menu symbols) | Generated for this site | Not a commercial font — it's a small icon file created as part of the original site build. No license applies. | Created with [IcoMoon](https://icomoon.io) during the original build |

**About the SIL Open Font License:** the full license text and a plain-English
FAQ are available at [openfontlicense.org](https://openfontlicense.org). In
short, it allows unlimited free use in commercial projects; the only
restriction is that the font files cannot be sold by themselves.

**Bottom line:** there is no licensing cost or legal risk associated with any
font on the site. Nothing needs to be purchased, and nothing depends on
Webflow or any external font service.

---

_Where the fonts live in this project: the `.woff2` files are in
`public/fonts/`, and the `@font-face` declarations that load them are in
`src/app/webflow-shared.css`._
